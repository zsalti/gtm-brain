# Learning Loop - Review Before, Extract After

## Before Starting Strategy, Content, or Major Decision Work

1. Check claude-mem for relevant prior observations: `/mem-search` for the topic
2. Scan any existing strategy or framework documents for prior hypotheses and validated findings
3. If the task involves data claims or market assumptions, check whether similar claims were previously validated

**Don't re-derive what's already known. Don't contradict validated findings without flagging it.**

## After Completing Strategy, Content, or Major Decision Work

1. If new market data, buyer signals, or competitive intel surfaced - log to `memory/` as a reference or project memory
2. If a hypothesis or assumption was confirmed or contradicted - document the finding
3. If a new behavioral pattern or correction emerged - consider whether it belongs in your `.claude/rules/`

**This loop ensures learnings compound instead of repeating.**
